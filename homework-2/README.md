# Smart Campus Portal｜智慧校務管理系統

> 參考大學校務系統常見功能設計的網頁專案。**非國立金門大學官方網站，也不與任何校方系統連線。** 所有學生、課程、公告及成績資料均為虛構。

## 一、專案簡介

本專案使用 HTML、CSS、原生 JavaScript 建立學生校務入口網站。以實作校務需求為題，練習網頁切版、狀態管理、資料驗證、時間區間衝堂判斷、瀏覽器端資料儲存與響應式介面。

## 二、主要功能

| 功能 | 內容 |
| --- | --- |
| 登入頁面 | 用虛構示範帳號登入與登出；登入狀態存在 sessionStorage |
| 儀表板 | 顯示已選學分、課程數、示範成績與公告 |
| 線上選課 | 搜尋、篩選、加選、退選，檢查衝堂與名額 |
| 每週課表 | 依照已選課程生成星期一至五的節次視圖，支援列印 |
| 成績查詢 | 示範歷史成績、學分加權平均及 GPA |
| 請假申請 | 新增請假、檢視本地紀錄（不會送交學校） |
| 個人資料 | 修改展示名稱、Email 和電話，重設展示資料 |
| 響應式設計 | 支援電腦、平板與手機瀏覽 |

## 三、執行方式

**方式 A：直接開啟**：解壓縮 ZIP 後雙擊 `index.html`。

**方式 B：VS Code**：使用 VS Code 開啟資料夾，安裝 Live Server 擴充套件，右鍵 `index.html` → Open with Live Server。

**方式 C：Python 本地伺服器**：在專案資料夾開啟終端機，執行：

```bash
python -m http.server 8000
```

瀏覽 `http://localhost:8000`。

不需要 API Key、不需要資料庫，也不需要安裝第三方套件。介面字型可連網載入 Google Fonts，離線時會使用系統字型。

## 六、程式核心概念

### 1. 選課衝堂檢查

每門課記錄星期 `day`、開始節次 `start`、節數 `length`，兩個課程的上課時間重疊時不能同時加選：

```js
function conflict(a, b) {
  return a.day === b.day &&
    a.start < b.start + b.length &&
    b.start < a.start + a.length;
}
```

例如課程 A 在星期二第 3–5 節、課程 B 在星期二第 3–5 節，系統會禁止同時選取。

### 2. 學分統計

使用 `reduce()` 加總已選課程學分，選課異動後同步更新總覽、表格與課表。

### 3. 本地資料儲存

使用 `localStorage` 保存選課、個人資料及請假紀錄；重新整理頁面後仍可讀取。使用 `sessionStorage` 記錄示範登入狀態。

### 4. 防止基本 HTML 注入

將使用者輸入插入動態 HTML 前進行 HTML 字元轉義，避免直接將未處理輸入解析為標籤。

## 七、功能測試建議

1. 使用 `demo` / `demo123` 登入。
2. 進入「線上選課」，搜尋 `資訊安全`，驗證它與「作業系統」衝堂，因此無法直接加選。
3. 先退選「作業系統」，再加選「資訊安全」，檢查課表與學分同步更新。
4. 重新整理網頁，確認選課結果保留。
5. 到「請假申請」新增一筆請假，檢查紀錄出現。
6. 到「個人資料」更新顯示名稱，回到首頁確認更新。
7. 測試手機尺寸、列印課表及登出。

## 八、已知限制

- 本專案是純前端展示，沒有伺服器及正式身分驗證，不適合直接管理真實學生資料。
- 課程名額為預設示範值；加選不會修改全校總名額，僅保存目前瀏覽器的選課清單。
- 成績與 GPA 使用示範換算方式，不代表任何學校的正式計算標準。
- 請假僅模擬送出，不具有校務審核或通知功能。
- 正式上線需另建後端、資料庫、權限管理、稽核、資安保護及正式 API。
