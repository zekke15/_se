# CampusMate｜智慧大學生活管理平台

參考 [UniMate 學生生活 Dashboard](https://julianalidya.github.io/_se/HW3/) 的核心概念，自行設計的繁體中文大學生生活管理網頁。**非金門大學官方系統，無任何校務系統連線。**

## 1. 專案動機與價值

學生的作業截止日、專注時間、生活費、筆記與課表分散在多個地方，容易忘記。CampusMate 讓學生在**同一個網站**整合日常資訊。

- **使用價值：** 讓大學生快速管理待辦、掌握時間、記帳，並檢查課程是否衝堂。
- **潛在商業價值：** 未來可提供雲端同步、多人共用、智慧提醒、進階報表等付費功能，或替系所、社團、補習班客製化。這只是商業構想，尚未驗證用戶付費意願。

## 2. 功能清單

| 功能 | 操作說明 |
| --- | --- |
| Dashboard | 顯示未完成任務、3 天內到期任務、今日專注分鐘、本月支出，以及近期事項 |
| Tasks | 新增、勾選完成、刪除任務；記錄課程、優先度與截止日期；依完成狀態篩選 |
| Focus | 15/25/50 分鐘倒數；開始、暫停、重設；完整結束自動累積今日專注時間 |
| Expenses | 新增與刪除支出；按分類呈現當月金額比較 |
| Notes | 建立及刪除筆記；首頁快速筆記自動儲存 |
| Schedule | 新增與刪除每週課程；檢查同一天的時間衝堂 |
| Backup | JSON 匯出、匯入備份；可重設示範資料 |

## 3. 技術架構

| 層級 | 技術 | 用途 |
| --- | --- | --- |
| 介面 | HTML5 + CSS3 | 響應式側邊欄、卡片與表單 |
| 程式 | Vanilla JavaScript | CRUD、時間檢查、即時統計、倒數 |
| 儲存 | localStorage | 保留同一瀏覽器中的使用資料 |
| 部署 | GitHub Pages | 靜態網站免費公開展示 |

本專案**無需 API Key、後端、資料庫或額外套件**。資料不會在不同裝置間自動同步；清除瀏覽器網站資料可能使紀錄遺失，請定期匯出備份。

## 5. 執行方法

1. 下載 ZIP 並解壓縮。
2. 直接雙擊 `index.html`，或用 VS Code 的 Live Server 開啟。
3. 左邊切換「總覽 / 作業 / 專注 / 記帳 / 筆記 / 課表」。

如果希望本機使用 HTTP 伺服器，也可在資料夾內執行：

```bash
python -m http.server 8000
```

然後開啟 http://127.0.0.1:8000/ 。

## 6. GitHub Pages 部署

1. 到 GitHub 建立公開 Repository，例如 `campusmate`。
2. 上傳 `index.html`、`css`、`js`、`README.md`（注意保留資料夾層級）。
3. 點選 `Settings → Pages → Build and deployment → Deploy from a branch`。
4. 設定 `main` 分支及 `/(root)`，儲存。
5. 部署完成後網址通常為 `https://你的帳號.github.io/campusmate/`。

GitHub Pages 是公開展示用靜態網站，**使用者資料仍儲存在各自瀏覽器的 localStorage**，沒有後端帳號管理；不要用來儲存敏感資訊。

## 7. 測試建議

- 新增任務，確認首頁未完成數加一；勾選完成後減一。
- 新增今天截止的任務，確認近期任務及截止資訊正確。
- 新增記帳，確認當月累計金額、分類長條更新。
- 新增同一天時間重疊的課程，確認系統拒絕衝堂。
- 新增筆記後重新整理，確認資料仍保留。
- 匯出 JSON、重設資料，再匯入 JSON，檢查資料還原。
- 番茄鐘倒數完整完成後，確認今日學習時間有增加。

**實作驗證：** 已以 `node --check js/app.js` 通過 JavaScript 語法檢查；尚未以真實瀏覽器完整跑完上述功能測試。

## 8. 提交作業的價值說明

> 我的專案名稱是 **CampusMate 智慧大學生活管理平台**。它的使用價值在於將大學生每天需要的作業追蹤、時間管理、生活記帳、快速筆記與課表整合在一個網頁中，減少在多個平台切換的時間。專案採用 HTML、CSS、JavaScript，能直接在 GitHub Pages 展示，並使用 localStorage 保留資料。未來可擴充雲端同步、團隊管理和進階分析，探索訂閱制或校園客製化服務的商業模式。
